# ⚔️ Function Guessing Game

**グラフを見て、正しい関数を当てよう！**

表示されたグラフを見て、対応する関数式を4つの選択肢から選ぶゲーム。

正解するとモンスターにダメージ。不正解だと自分のHPが減っていく。全15レベル、最後までクリアできるか挑戦してみよう！

以下のサイトでプレイ
https://ndegital.github.io/function-guessing-game/
## ゲームの特徴

- 全15レベルのモンスター
- グラフを見て関数を当てる4択クイズ
- レベルが上がるにつれて問題も難しくなる
- 正解・不正解に応じてHPが変化するバトル形式

## 遊び方

1. ゲームを開始する
2. 挑戦するモンスターを選ぶ
3. 表示されたグラフに合う関数式を選択する
4. 正解してモンスターのHPを0にする

自分のHPは3、モンスターのHPは10。
3回間違えるとゲームオーバー。
