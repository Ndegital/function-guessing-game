# ⚔️ Function Guessing Game

**グラフを読み解き、数式でモンスターを討て。**

関数のグラフを見て、正しい数式を選ぶ数学クイズゲーム。  
レベルが上がるほど問題も難しくなり、全15体のモンスターがあなたの挑戦を待っている。

## 🎮 Features

- **全15レベル**：自分の実力に合わせてモンスターを選択
- **ランダム出題**：一次・二次・三次関数や三角関数など、さまざまな関数が登場
- **4択クイズ**：グラフから正しい関数式を推理
- **HPバトル**：正解でモンスターにダメージ、不正解で自分のHPが減少
- **演出とサウンド**：グラフの描画アニメーションを搭載
- **レスポンシブ対応**：PCからプレイ可能

## 🕹️ How to Play

1. スタート画面からゲームを開始
2. 挑戦するモンスター（レベル）を選択
3. 表示されたグラフに対応する関数式を4択から選ぶ
4. 正解を重ねてモンスターのHPを0にすればクリア！

**自分のHPは3、モンスターのHPは10。**  
3回間違えるとゲームオーバーです。
